# 🎓 Lingua-AI — адаптивный AI-репетитор английского (рабочее имя)

PWA, которая учит **русскоговорящих пользователей английскому языку**, подстраивая методику под каждого ученика. Ключевая фишка — не контент (его много у всех), а **движок памяти про юзера**: система запоминает, какая концепция подачи материала на конкретном человеке работает лучше, и адаптируется.

## Рыночный угол (против Duolingo — для рекламы)

Не «убийца Duolingo», а **другой жанр**. Главная слабость Duolingo — учит всех одинаково. Атакуем 3 точки:
1. **«Один путь для всех» → персональная методика.** Мы запоминаем, КАК именно этот человек учится лучше (rule-first / примеры / сравнение с русским), и ведём преимущественно так.
2. **«Учит узнавать, не говорить» → speaking с дня 1** (заложен в архитектуру, включается поэтапно).
3. **«Не объясняет грамматику» → объясняем на русском**, под уровень.

**Рекламный посыл (1 строка):** «Персональный AI-репетитор, который запоминает, КАК ты учишься лучше — и ведёт именно так».

**Честные риски позиционирования:** speaking-ниша занята (Speak ~$1B, Praktika); адаптивность трудно показать в 15-сек крео; доверие к «AI-учителю» ниже, чем к бренду. → Демо «замера концепции» (какая подача тебе зашла) — это и есть визуальный вау для крео.

## Что строим (видение продукта)

1. **Диагностика уровня** — адаптивный placement-тест (следующий вопрос зависит от ответа на предыдущий). Выдаёт CEFR-уровень (A1–C2) + карту слабых тем.
2. **Профиль ученика** — на юзера хранится: уровень по навыкам (грамматика/лексика/аудирование/чтение/speaking), карта слабых тем, **предпочитаемая концепция подачи**.
3. **Движок концепций подачи** — одна тема даётся в 2–3 стилях объяснения; замеряем результат (% правильных + удержание через день); закрепляем рабочий стиль, изредка пробуем новый.
4. **Цикл закрепления** — spaced repetition (кривая забывания, как Anki). Тему не бросаем до автоматизма, только потом идём дальше.
5. **Аудирование** — AI озвучивает фразы (Gemini TTS), юзер понимает на слух.
6. **Speaking** — юзер говорит, AI оценивает произношение. ⚠️ Самый дорогой/хрупкий блок. Заложен в архитектуру с дня 1, включается поэтапно.

## Концепции подачи (ядро адаптивности)

Разные стили объяснения ОДНОЙ темы:
- **rule-first** — формула → примеры → практика
- **examples-first** — много примеров → юзер сам выводит правило
- **context-story** — тема внутри диалога/ситуации
- **contrast-native** — сравнение «как в русском vs как в английском»

Метрика выбора концепции: не только `% правильных` в моменте, но и **retention через 1 день** (это честнее, ловит «понял на минуту vs запомнил»). Решение о смене концепции — НЕ раньше 3–5 сессий накопления сигнала (на 1–2 уроках статистика шумная).

## Решённые параметры (от владельца)

- **Формат:** PWA (worldwide без сторов, установка на телефон).
- **Аудитория v1:** русскоговорящие, учат английский. UI и объяснения на русском, материал — английский.
- **Объём:** speaking + аудирование НУЖНЫ (заложить в архитектуру сразу).

## Стек (зафиксирован билдом — Фаза 1)

- **Frontend:** Next.js 16 (App Router, src-dir) + React 19 + TypeScript + Tailwind 4. Анимации — Motion.dev (добавляется по мере портирования визуала). PWA-манифест + service worker.
- **Бэкенд/БД:** Supabase (Postgres + auth + storage) — профили юзеров, прогресс, spaced-repetition записи. Облачный инстанс подключается через `.env` (см. ниже). До подключения профиль работает через слой-абстракцию (`src/lib/store/`), бэкенд localStorage → Supabase меняется одним адаптером.
- **LLM:** Claude (генерация упражнений, проверка ответов, объяснения). Слой валидации качества заданий обязателен. — Фаза 3.
- **TTS (аудирование):** Gemini TTS (вердикт владельца — лучший TTS; бесплатный). — Фаза 4.
- **STT/оценка произношения (speaking):** TBD — кандидаты Whisper + отдельная оценка фонетики. Самый рискованный блок, прототипировать отдельно. — после MVP.

## Фазы разработки (роадмап)

- **Фаза 1 — Каркас (текущая):** скаффолд Next+PWA+Supabase-слой; профиль ученика из JS-переменной → в БД/абстракцию; порт визуала прототипов в React.
- **Фаза 2 — Ядро памяти:** движок концепций + spaced repetition как сервис (пишет в БД, копит сигнал 3–5 сессий, выбирает концепцию). Главное отличие от Duolingo.
- **Фаза 3 — AI-генерация:** Claude генерит упражнения под слабые темы + слой валидации.
- **Фаза 4 — Listening + Speaking-демо:** Gemini TTS (озвучка); speaking — отдельный прототип, не блокирует запуск.

## Как запускать / тестить / деплоить

```bash
pnpm install          # установка зависимостей
pnpm dev              # дев-сервер (http://localhost:3000)
pnpm build            # прод-сборка
pnpm start            # запуск прод-сборки
pnpm lint             # ESLint
```

Деплой: Vercel (frontend) + Supabase (managed БД). Перед деплоем завести облачный Supabase-проект и прописать ключи в `.env` (NEXT_PUBLIC_SUPABASE_URL / NEXT_PUBLIC_SUPABASE_ANON_KEY).

> ⚠️ Next.js 16 — версия со свежими breaking changes. Перед нетривиальной правкой по фреймворку сверяйся с `node_modules/next/dist/docs/` (см. AGENTS.md).
